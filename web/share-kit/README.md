# Share kit

Made by `npm run share-kit` (in `web/`) from `src/lib/site.ts`. Re-run it after changing the
address or the wording there.

| File | Use |
|------|-----|
| `poster-a5.pdf` | Print at **100% / actual size** on A5 (or A4 and cut). White paper; only the top panel is dark. |
| `poster-a5.png` | The poster as an image, to check it or send it to a print shop. |
| `share-square.png` | 1080x1080: Instagram post, WhatsApp image. |
| `share-story.png` | 1080x1920: Instagram / WhatsApp story. On Instagram, add a link sticker to the short link. |
| `qr-rate.svg` / `qr-rate.png` | The QR code alone. |
| `../public/og.png` | 1200x630 picture shown when someone shares the app's link. |

**Short link:** https://surfwithai.vercel.app/rate opens the app with the rating form already up.

Message to paste (WhatsApp / Instagram bio / Telegram):

> Surfed Vilanova today? Rate the waves in 3 taps and help train a better forecast 🌊
> https://surfwithai.vercel.app/rate

Before printing, scan the QR on screen with your phone and check it opens the rating form.
